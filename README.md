# 🔢 Generador de Números Primos

Aplicación desarrollada con Flutter y Dart que permite explorar la secuencia de números primos de manera interactiva. A través de una interfaz sencilla, el usuario puede generar nuevos números primos y visualizar la lista actualizada en tiempo real.

---

## 📋 Descripción General

Este proyecto tiene como objetivo poner en práctica conceptos fundamentales de Flutter, como la gestión de estados, la construcción de interfaces dinámicas y la manipulación de listas.

La aplicación calcula y muestra números primos secuencialmente, permitiendo al usuario agregar o eliminar elementos mediante controles interactivos.

## ✨ Características

* Generación automática de números primos.
* Actualización dinámica de la interfaz.
* Visualización organizada de los números generados.
* Botón para añadir el siguiente número primo.
* Botón para eliminar el último número de la lista.
* Diseño simple e intuitivo.

## 🚀 Ejecución del Proyecto

1. Clonar el repositorio:

```bash
git clone https://github.com/Odaliz2105/Flutter_Aplication.git
```

2. Ingresar al proyecto:

```bash
cd Flutter_Aplication
```

3. Instalar dependencias:

```bash
flutter pub get
```

4. Ejecutar la aplicación:

```bash
flutter run
```

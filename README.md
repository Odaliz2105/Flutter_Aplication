<h1 align="center">Generador de Números Primos con Flutter</h1>

## Descripción

Este proyecto fue desarrollado en Flutter como práctica de introducción al framework. La aplicación permite generar números primos de forma dinámica mediante un botón y mostrarlos en pantalla organizados en columnas.

---
## Autora

Nayely Ayol

---
## Funcionalidades

* Generación de números primos.
* Visualización de los números primos generados.
* Botón para agregar el siguiente número primo.
* Botón para eliminar el último número primo generado.
